# 🎮 Tetris Game (C++ & SFML)

A feature-rich and visually polished clone of the classic **Tetris**, developed using **C++** and the **SFML** graphics library. This game includes multiple modes, background music, and a persistent high score leaderboard — blending nostalgic gameplay with modern enhancements.

---

## 🚀 Features

- 🧱 **Two Block Modes** – Choose between classic and custom block styles  
- 🎵 **Background Music** – Retro soundtrack for a more immersive experience  
- 🏆 **High Score Leaderboard** – Saves and displays top scores across sessions  
- ⏫ **Increasing Difficulty** – Game speeds up as you clear more lines  
- 🎮 **Smooth Controls** – Responsive and fluid keyboard input  
- 🔄 **Restart Option** – Instantly restart after game over  
- 🌈 **Clean UI & Animation** – Built using SFML for smooth visuals  

---

## 🛠️ Tech Stack

- **Language:** C++  
- **Graphics & Audio:** SFML (Simple and Fast Multimedia Library)
- **Note:** Make sure SFML is installed on your device
